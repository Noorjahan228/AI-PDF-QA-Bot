# 🤖 AI-PDF-QA-Bot

An intelligent document-based Question-Answering application built with Python. This tool allows users to upload PDF documents and interact with them by asking natural language questions, getting accurate context-aware responses instantly.

---

## 🚀 Features
* **PDF Document Upload:** Supports seamless uploading of any standard PDF file.
* **Contextual Q&A:** Extracts precise answers from the document rather than generic web responses.
* **Interactive UI:** Built with an intuitive and clean interface for smooth user experience.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Frontend / UI:** Streamlit
* **AI / ML Framework:** LangChain / Generative AI APIs
